# Offline geographic asset

`world_110m.json` is the Plotly geographic asset from https://cdn.plot.ly/world_110m.json, downloaded 2026-10-28 for offline PDF rendering. The geometry derives from Natural Earth public domain map data. Plotly's geographic assets are maintained at https://github.com/plotly/plotly.js/tree/master/dist/topojson.

Do not fetch geographic assets while rendering capture-derived reports. Update this vendored asset only as a reviewed source change.
